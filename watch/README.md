# HealthGo na zegarki — wersja Alpha

Pierwszy etap obejmuje dwa główne systemy zegarków:

- Apple Watch (watchOS) — SwiftUI + Firebase AI Logic
- Wear OS — Kotlin/Compose for Wear OS + Firebase AI Logic

## Co będzie w pierwszej wersji

- ekran główny HealthGo,
- HealthGo AI z krótkimi pytaniami,
- szybki status połączenia,
- przygotowane miejsce pod Plan Dnia i Aktywność.

Nie pokazujemy fikcyjnych kroków, tętna ani snu. Dane zdrowotne będą dodane dopiero po podłączeniu prawdziwych API i uzyskaniu zgody użytkownika.

## Ważne

### Apple Watch
Do zbudowania i uruchomienia aplikacji Apple Watch potrzebny jest Mac z Xcode. Kod źródłowy znajduje się w `watch/apple-watch`.

### Wear OS
Wear OS można rozwijać na Windowsie w Android Studio. Kod źródłowy znajduje się w `watch/wear-os`.

## Inne zegarki

Samsung Galaxy Watch 4 i nowsze modele z Wear OS korzystają z wersji Wear OS. Garmin, Huawei i część Amazfit używają innych platform i wymagają osobnych aplikacji.
